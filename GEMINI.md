# Federal Grant Evidence

Use `search_federal_grants` for discovery and `analyze_federal_grant` for the free cited preview. Use `get_federal_grant_evidence_pack` only when the user explicitly wants the complete pack after the free result has been shown.

Never present the product as an official eligibility decision, award prediction, application-writing service, or submission service. Preserve `PASS`, `FAIL`, and `UNKNOWN` as distinct evidence states. The current public payment rail is Base Sepolia testnet; test USDC has no real monetary value and mainnet settlement is locked.
